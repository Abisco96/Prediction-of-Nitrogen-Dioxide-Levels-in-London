# 📊 Prediction of Nitrogen Dioxide (NO₂) Levels in London

## 🚀 Project Overview
This project develops a **machine learning model to predict nitrogen dioxide (NO₂) levels in London** using historical air quality data.

The goal is to improve understanding of pollution trends and support **data-driven decision-making** for urban environments.

---

## 🎯 Objectives
- Analyse historical air quality data in London  
- Build predictive models for NO₂ concentration  
- Identify key factors influencing air pollution  
- Evaluate model performance using regression metrics  

---

## 🌍 Background
Nitrogen dioxide (NO₂) is a major air pollutant produced by fuel combustion and is strongly linked to traffic emissions. It remains a key concern in urban environments due to its impact on public health.

---

## 📊 Dataset
- Source: London Air Quality Dataset  
- Measurements include:
  - Nitrogen Dioxide (NO₂)
  - Nitric Oxide (NO)
  - Ozone (O₃)
  - Particulate Matter (PM10, PM2.5)
- Units: µg/m³  
- Data includes both **roadside and background measurements**

---

## 🧠 Methodology

### 🔧 Data Processing
- Cleaned and preprocessed raw data  
- Handled missing values  
- Performed feature selection  
- Normalised/standardised variables

### 🤖 Models Used

### 📈 Evaluation Metrics
